# 表格管家 · Sheet Butler

> **一句话:Excel / CSV 的脏活累活 —— 合并、拆分、对账、清洗、汇总 —— 一条命令搞定。**
>
> **零依赖**:不装任何第三方库(npm / pip 都不用)。**自带 Excel 读写引擎**(自己解析 .xlsx 的 zip+XML 结构)。
> 有电脑 + Node 就能跑,双击即可,交付给不懂技术的客户也能用。

---

## 一、五个任务

| 任务 | 解决什么 | 典型场景 |
|---|---|---|
| **`reconcile` 对账** ⭐ | 两张表逐行比对,找出「只在 A 有 / 只在 B 有 / 两边都有但金额不一致」 | 订单 vs 台账、系统导出 vs 手工表、应收 vs 实收 |
| **`merge` 合并** | 把 N 张表合成一张(表头自动对齐、记录来源文件、可去重) | 12 个月的月报合成年报 |
| **`split` 拆分** | 按某列的值拆成多个文件 | 一张总表按地区/按门店拆开 |
| **`clean` 清洗** | 去空格、删空行、去重、类型规范化、条件过滤 | 从系统导出的脏数据 |
| **`summarize` 汇总** | 分组统计(求和/平均/计数/最大最小/去重数)+ 自动合计行 | 按状态/按地区出汇总表 |

## 二、两种用法

### A. 网页版(推荐给客户用)⭐

```bash
node webui.mjs          # 启动 → 浏览器打开 http://127.0.0.1:4220/
```

**客户只要拖文件进去、点几下、下载结果 —— 完全不用碰命令行。**

| 界面 | 实际行为 |
|---|---|
| **拖拽上传** | 支持 .xlsx / .csv / .tsv,单个最大 50MB |
| **选择文件** | 对账时点一下文件就标记成「左表 A」「右表 B」 |
| **选任务** | 5 个任务卡:对账 / 合并 / 拆分 / 清洗 / 汇总 |
| **列名自动读取** | 从你上传的表里读出真实列名,变成下拉框(还会告诉你列名来自哪个文件) |
| **开始处理** | 真的执行,返回摘要 + 明细表 |
| **下载结果** | 一键下载生成的 Excel/CSV |

**安全设计(这是重点)**

| 措施 | 说明 |
|---|---|
| **只绑 `127.0.0.1`** | 局域网 / 其他设备**访问不到** |
| **只服务两个目录** | `public/`(前端)与 `webdata/`(上传与输出),其他一律 404 |
| **路径穿越防护** | `/../config.json`、`..%2f`、下载接口的 `../` **全部被拒绝**(已实测) |
| **文件名安全化** | `../../偷偷逃出去.csv` → 路径分隔符与 `..` 全部清理 |
| **类型与体积限制** | 非表格文件被拒绝并给出原因;单次上传上限 50MB |
| **数据不出本机** | 上传的表格只存在你电脑的 `webdata/` 里,不发往任何服务器 |

## 三、配置怎么写(命令行方式)

### 对账(最值钱的功能)

```json
{
  "task": "reconcile",
  "inputs": { "a": "订单系统导出.xlsx", "b": "财务台账.csv" },
  "output": "out/对账结果.xlsx",
  "options": {
    "keyColumns": ["订单号"],
    "compareColumns": ["金额", "状态"]
  }
}
```

输出是一个 **4 个工作表的 Excel**:
```
汇总        —— 各分类条数 + 一句结论(如「⚠ 有 4 处差异需要核对」)
仅左表有    —— A 有 B 无(漏记/未同步)
仅右表有    —— B 有 A 无(多记/重复)
值不一致    —— 两边都有但字段不同,并排给出左右值 + 差异说明
```

**无需人工比对,打开就知道差在哪。** 差异明细长这样:

| 订单号 | 金额(左) | 金额(右) | 金额·是否一致 | 说明 |
|---|---|---|---|---|
| A009 | 980 | 990 | 不一致 | 金额:980 ≠ 990 |

### 合并

```json
{
  "task": "merge",
  "inputs": ["月度报表-*.csv"],
  "output": "out/合并结果.xlsx",
  "options": { "sourceColumn": "来源文件", "dedupeBy": ["订单号"] }
}
```
- `inputs` 支持 **通配符**(`*.csv`)、**目录**、**多个文件**
- `sourceColumn` 会加一列记录每行来自哪个文件
- `dedupeBy` 按指定列去重

### 拆分 / 清洗 / 汇总

```json
{ "task": "split", "inputs": ["总表.xlsx"], "outputDir": "out/按地区拆分",
  "options": { "by": ["地区"], "format": ".xlsx", "topN": 10 } }

{ "task": "clean", "inputs": ["脏数据.csv"], "output": "out/清洗后.xlsx",
  "options": { "trim": true, "dropEmptyRows": true, "dedupeBy": ["手机号"],
               "columns": { "金额": "number", "日期": "date" },
               "filter": { "column": "状态", "op": "eq", "value": "已付" } } }

{ "task": "summarize", "inputs": ["明细.xlsx"], "output": "out/汇总.xlsx",
  "options": { "groupBy": ["地区"],
               "aggregations": [
                 { "column": "订单号", "op": "count", "as": "订单数" },
                 { "column": "金额", "op": "sum", "as": "金额合计" },
                 { "column": "金额", "op": "avg", "as": "平均金额" } ] } }
```

**可选聚合方式:** `sum` / `avg` / `count` / `max` / `min` / `distinct`

## 四、中文场景专门处理过的坑

| 坑 | 本工具怎么处理 |
|---|---|
| **Excel 导出的 CSV 是 GBK 编码** | **自动识别**:先按 UTF-8 解,出现乱码自动回退 GBK |
| CSV 里带逗号 / 换行 / 引号 | 完整 RFC4180 解析(引号转义、字段内换行) |
| 分隔符是分号或制表符 | 自动探测(逗号 / 分号 / 制表符 / 竖线) |
| **导出的 CSV 在 Excel 里乱码** | 输出**带 BOM**,双击直接正常显示 |
| 数字带千分位 / 货币符号 | `¥1,234.50` → `1234.5`,自动识别 |
| 表头重复 / 有空格 | 自动去空格、重名加后缀,不会互相覆盖 |
| 日期显示成一串数字 | 读 xlsx 时按样式识别日期格式,自动还原成日期 |

## 七、技术结构

```
02-sheet-butler/
├── butler.mjs            主程序(CLI)
├── config.json           默认配置(= 对账)
├── demo.mjs              一键生成示例数据
├── selftest.mjs          全量自检入口
├── selftest-xlsx.mjs     底层自检(38 项)
├── selftest-tasks.mjs    任务自检(39 项)
└── lib/
    ├── zip.mjs           零依赖 ZIP 读写(zlib + 自写 CRC32 / 中央目录)
    ├── xlsx.mjs          零依赖 XLSX 读写(XML 解析 + 日期样式识别)
    ├── csv.mjs           CSV 读写(GBK 自动识别 / 分隔符探测 / 类型推断)
    ├── table.mjs         统一表格模型(CSV 与 XLSX 同一套逻辑)
    └── tasks.mjs         五个任务实现
```

**为什么值得说:** `.xlsx` 本质是 zip + XML。这里没有用任何现成库 —— ZIP 的中央目录、CRC32、deflate、XML 解析、Excel 的日期序列号与 1900 闰年 bug,全部自己实现。**整个项目零依赖,拷到任何装了 Node 的电脑上都能跑。**
